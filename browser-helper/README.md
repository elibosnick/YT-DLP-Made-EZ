# YT-DLP Made EZ Chrome Helper

This optional helper connects an already-open Chrome tab to the desktop app through
`127.0.0.1`. It does not upload cookies, page content, or video data. Click the
extension button while a video is playing; the detected URL is placed in the app.

This first version is for non-DRM media URLs exposed by the page. To install during
development, open `chrome://extensions`, enable Developer mode, choose Load unpacked,
and select this folder.
